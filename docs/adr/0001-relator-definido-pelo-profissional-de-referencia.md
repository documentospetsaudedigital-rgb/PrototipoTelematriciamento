# Relator definido apenas pelo Profissional de Referência

O modelo do REQ guarda o Relator na Reunião de matriciamento (`relator_id`), mas o RF20 permite que o Profissional da UBS também o defina. Uma Reunião pode reunir Casos de várias UBS, e não há regra para decidir qual Profissional da UBS escolheria. Por isso, no protótipo, só o Profissional de Referência define o Relator, uma vez por Reunião.

Esta decisão é provisória. Ela precisa ser validada com os profissionais de saúde nas sessões do protótipo antes de entrar no PRD como definitiva. A divergência com o RF20 está registrada em "Divergências resolvidas".
