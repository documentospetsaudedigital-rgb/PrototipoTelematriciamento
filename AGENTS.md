# AGENTS.md

## Agent skills

### Issue tracker

Issues live as GitHub issues in `documentospetsaudedigital-rgb/PrototipoTelematriciamento` (via `gh`). See `docs/agents/issue-tracker.md`.

Issues labelled `spec` (e.g. #1) are specs, not tickets: never implement one directly. Implement its sub-issues instead.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
